# AI Skills for University

แพลตฟอร์มคอร์สเรียนออนไลน์สำหรับมหาวิทยาลัย  
พัฒนาโดย **ทีมงาน ลาบเลิฟเวอร์**

## เริ่มต้นใช้งาน

1. Clone หรือดาวน์โหลดโปรเจกต์นี้
2. เปิดโฟลเดอร์ด้วย VS Code
3. เปิดไฟล์ `index.html` ด้วย Live Server หรืออัปโหลดไปที่ GitHub Pages
4. แก้ไขไฟล์ `js/config.js` ด้วย URL และ Anon Key จาก Supabase Project ของคุณ

## เทคโนโลยี

- HTML5, CSS3, Tailwind CSS, DaisyUI, Bootstrap 5
- Vanilla JavaScript (ES Modules)
- Supabase (Auth, Database, Storage)
- Chart.js, Quill.js
