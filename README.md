# AI Skills for University

เว็บไซต์สื่อการเรียนรู้เกี่ยวกับ AI สำหรับนักศึกษามหาวิทยาลัย

## Objectives

- ให้ความรู้เกี่ยวกับ AI
- เปรียบเทียบ AI ยอดนิยม
- แนะนำการเลือกใช้งาน AI
- มี Workshop และแบบประเมินผล

## Target Audience

นักศึกษามหาวิทยาลัยชั้นปีที่ 1-3 ที่ไม่ได้อยู่ในสายเทคโนโลยีสารสนเทศ
